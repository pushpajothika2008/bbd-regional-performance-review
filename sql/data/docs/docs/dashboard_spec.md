# Tableau Public Dashboard Specification

## Layout Structure
1. **Header KPI Cards:**
   - Total Revenue (INR)
   - Total Completed Orders
   - Average Order Value (AOV)

2. **Visualizations:**
   - **Regional Revenue Breakdown:** Bar chart comparing revenue across North, South, East, West.
   - **Sales Rep vs Target:** Bullet chart comparing actual revenue vs `monthly_target`.
   - **Category Performance:** Donut chart showing category revenue distribution.

3. **Global Filters:**
   - Region Slicer
   - Month Filter (`2026-09`, `2026-10`)
